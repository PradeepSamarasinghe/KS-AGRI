# 🥭 KS AGRI Export Platform  

A modern and responsive **full-stack export management platform** built with **React.js**, **Tailwind CSS**, **Framer Motion**.  
This platform showcases **Sri Lankan agricultural products** (cassava, papaya, king coconut, coconut, etc.), enabling buyers to explore products, send inquiries, and connect directly with exporters.  

---

## ✨ Features  

- 🎨 **Modern UI/UX** — Clean, professional, and responsive design  
- 🌀 **3D Animations** — Interactive product sections and smooth hover effects  
- ⚡ **Dynamic Frontend** — React.js with Framer Motion for animations  
- 📦 **Product Showcase** — Export products with categories & descriptions  
- 📨 **Contact & Inquiry Forms** — Buyers can send bulk inquiries easily   
- 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile

## 🚀 Getting Started  

### 1️⃣ Clone the repository  
```bash
git clone https://github.com/PradeepSamarasinghe/ks-agri.git
```
### 2️⃣ Navigate into the project folder
```bash
cd ks-agri
```
### 3️⃣ Install dependencies
```bash
npm install
```
### 4️⃣ Run the development server
```bash
npm run dev
```
